# Vox Reader: offline text to speech for EPUB books on Windows

Vox Reader reads DRM-free EPUB books, TXT files and pasted text aloud with natural English voices that run on your PC. Once installed, listening works offline. Sentence highlighting, bookmarks, saved positions and a sleep timer are included.

**Get it:** [Microsoft Store](https://apps.microsoft.com/detail/9PCVQB5H684W) · **Website:** [tendercrafthq.com/apps/vox-reader](https://tendercrafthq.com/apps/vox-reader)

## Free and Pro

| | Free | Pro (one-time purchase, no subscription) |
|---|---|---|
| EPUB, TXT and pasted text | Yes | Yes |
| Voices | 3 | All 11 |
| Listening time | 3 hours a week | Unlimited |
| Text-based PDF and Word (DOCX) import | No | Yes |
| Custom pronunciations | No | Yes |

## Limits

- Windows 10 (19041 or newer) and Windows 11, x64
- English only
- DRM-free files only; scanned image-only PDFs need text recognition first
- About 460 MB to download, because the voices are bundled
- Store purchase and licence refresh need an internet connection
